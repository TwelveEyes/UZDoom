**Map:** `../map.md`

**Status:** resolved
**Blocked by:** 04

## What to build

1. Port `LegacyWorldRenderer.Bsp` traversal fully (BSP mode) and the adaptive heuristic (`IBspHeuristics` implemented by `BspHeuristics.cpp` timing the BSP walk with `hw_clock.h` timers); `gl_rendermode*` CVars (D28). Static mode: `IterateBlockmap` with `r_distance_cull_type`/culldist as `MaxDistance` (0 = whole map, like Helion's 0).
2. `PortalRenderer` extensions (UZDoom-only files under `Geometry/Portals/`): `LinePortal`, `MirrorPortal`, `LineToLinePortal`, `SkyboxPortal`, `SectorStackPortal`, `PlaneMirrorPortal`, `HorizonPortal`, `EEHorizonPortal` (one class per `hw_portal.h` type, same math), each: `DrawPortalStencil` with `PortalStencilProgram`, then `LegacyWorldRenderer::PerformRender` recursion with the portal's `FRenderViewpoint`, clip plane set via `FRenderState::SetClipLine`/`SetClipHeight`/`EnableClipDistance`, `r_portal_recursions`, `r_mirror_recursions`, `gl_noskyboxes`, `r_skyboxes` honoured; portal groups from `r_data/portalgroups.cpp`. Translucent portal planes go to the sorted bucket.
3. Polyobjects (D27), `r_radarclipper`/fog-of-war forcing BSP mode, `r_fakecontrast`/`gl_seamless`/`gl_texture_usehires`/`WALLF_*` wall flags, texture warp (`func_warp.fp` warp modes as `boundTexture` program variants `SHADERTYPE_WARP1/2`), `gl_mask_threshold`, `r_dithertransparency` (`EFFSHADER_Dithertrans` equivalent), special colormaps/`fixedcolormap` (`SetSpecialColormap` stays in the entry point), `r_ab_fullbright` (D24).
4. Camera/canvas textures: `screen->RenderTextureView(FCanvasTexture*, ...)` callback renders via `Helion_RenderViewpoint(..., mainview=false, toscreen=false)` exactly as `hw_entrypoint.cpp:298-387` does; save pictures via `WriteSavePic` path unchanged except dispatch.
5. Acceptance: Pirates! MAP58 (sky/portals), HEXEN MAP01/MAP10 (polyobjects), `3dfloortest.wad`, `citadel.pk3` render without black regions or missing portals in all three `gl_rendermode` values; captures per §V2.
