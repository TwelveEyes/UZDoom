## What to build

1. Port `Entities/**` (minus `EntityHealthBarProgram`), `Primitives/**` (used for tracers/debug lines; keep), `Framebuffer/OitFrameBuffer`, `Renderers/FramebufferRenderer`. `EntityVertex` (Helion fields) extended with: `Roll (float)`, `Scale (vec2)`, `LightProbe (vec4, SetDynLight colour)`, `TranslationIndex (float)`, `OrientationMode (packed into RenderOptions: 0 XY-billboard, 1 Y-billboard, 2 face-camera, 3 flat sprite, 4 wall sprite, bit flags xflip/yflip/rollcenter/stretchpixels/onesided)`, `FuzzType`, `Alpha`. The vertex shader expands the quad per mode (math copied from `hw_sprites.cpp` `CalculateVertices` incl. `gl_billboard_mode`, `gl_billboard_faces_camera`, `gl_billboard_particles`, `hw_force_cambbpref`, `RF_ROLLSPRITE`/`RF_ROLLCENTER`/`RF2_ANGLEDROLL`, `RF_FLATSPRITE`, `RF_WALLSPRITE`, `RF_MASKROTATION` resolved on the CPU when emitting). Sprite clipping: `gl_spriteclip` modes computed on CPU as today (`PerformSpriteClipAdjustment`) and written into `OffsetXYZ`; Helion's `SpriteClip/SpriteClipMin/SpriteClipFactorMax` map to `gl_spriteclip` (no new CVar). Light: `GetDynSpriteLight` (`hw_spritelight.cpp`) → `LightProbe`; sector light via `lightLevelBufferIndex` like Helion; `gl_light_sprites`, `gl_light_particles`, `RF2_NODYNAMICLIGHTING`, `SPF_NODYNAMICLIGHTING`, `LEVEL3_NOCOLOREDSPRITELIGHTING`, `r_fullbrightignoresectorcolor`, `gl_enhanced_nightvision`/`gl_enhanced_nv_stealth`, `gl_fuzztype` (fuzz shader lumps `fuzz_*.fp` become `FragFunction` fuzz variants selected by `FuzzType`), `gl_sprite_blend`, `gl_mask_sprite_threshold`, `r_actorspriteshadowdist` + `RF_CASTSPRITESHADOW`/`RF_NOSPRITESHADOW` (shadow = second instance with shadow style), `r_distance_cull_type`/`gl_cullcolor` thick-fog cull, coronas (`gl_coronas`, `DrawCoronas` logic → `CoronaRenderer` after entities).
2. Particles and VisualThinkers emit `EntityVertex` instances too: `particle_t` (`p_effect.h:78-92`, `SPF_*` flags, `PT_SQUARE/ROUND/SMOOTH` via `gl_particles_style` → `FuzzType`-style shape bits drawing procedural quads when `texture` is invalid), `DVisualThinker` (`p_visualthinker.h`, `VTF_*`, `AdjustVisualThinker` logic). Gather: iterate `Level->ActiveParticles` list and `Level->VisualThinkers` (stat `STAT_VISUALTHINKER`) and cull against the render blockmap box/half-plane (static mode) or the ViewClipper (BSP mode).
3. Models/voxels: `Entities/EntityModelRenderer.{h,cpp}` implements `FModelRenderer` (`src/common/models/modelrenderer.h`; same methods as `FHWModelRenderer` in `hw_models.cpp`) on top of a `ModelProgram` (`RenderProgram` with `aVertex2`/`aNormal`/bones attributes from `hw_modelvertexbuffer.cpp:34-44`, bones SSBO/UBO via existing `BoneBuffer`, `gl_light_models`, `gl_model_light_optimization_radius`, `MDL_*` flags handled by `r_data/models.cpp` unchanged). Voxels stay `FVoxelModel` meshes. `r_drawvoxels`, `gl_interpolate_model_frames` honoured.
4. Weapon: `Entities/WeaponRenderer.{h,cpp}` ports `hw_weapon.cpp` (`HUDSprite`, `PSPF_*`, `r_deathcamera`, `gl_weaponlight`, weapon models via `RenderHUDModel`) drawing with the entity program in an orthographic HUD projection after the world, before OIT composite.
5. Decals: `Geometry/DecalRenderer.{h,cpp}` ports `hw_decal.cpp` (per-side decal lists `side_t::AttachedDecals`), drawn after opaque walls with polygon offset, sorted bucket when translucent.
6. OIT + sorted bucket (D10): `RenderTransparent` ported verbatim (transparent pass, fuzz pass, composite styles Translucent/FogBarrier/Add/ColorAdd). New `Data/SortedTranslucentRenderer.{h,cpp}` collects every D10-excluded draw (walls, flats, sprites, models, decals, portal planes) with its eye-space depth and draws back-to-front after the composite with per-item `SetRenderStyle` (styles from `hw_setcolor.cpp`'s mapping) — sort key = Helion's BSP order when in BSP mode, otherwise squared distance to the viewer.
7. Acceptance: DOOM2 MAP01 monsters/items/weapon/decals/particles (`gl_particles_style` 0..2) render; `gl_billboard_mode` 0/1, `gl_spriteclip` 0..3, `gl_fuzztype` 0..8 change output; a translucent (`STYLE_Translucent`) and a subtractive (`STYLE_Subtract`) test actor both render; captures per §V2.
