## What to build

1. Port `OpenGL/Texture/**`, `OpenGL/Textures/**`, `Common/Textures/**`, `OpenGL/Texture/Legacy/{LegacyGLTextureManager,GLTextureArrayBuilder,GLLegacyTexture,IArrayTexture}`: `LegacyGLTextureManager` sits beside `FMaterial`: for a `FGameTexture` with only base (+brightmap) layers it allocates a layer in a size-bucketed `GLTexture2DArray` (buckets from `GLTextureArrayBuilder.GetBucketIndex`, built at level load from the level's walls/flats/sprites exactly as `BuildLevel`/`BuildSprites`); pixels come from `FGameTexture::GetTexture()->GetBgraBitmap()` (truecolor) or `CreatePalettedPixels` (palette mode, uploaded as R8UI index + the `ColorMapBuffer` built from the loaded `COLORMAP`/palette via `GPalette`). Textures with extra layers or a custom shader report `IsArrayTexture()==false` and are drawn through the per-material path (`FRenderState::SetMaterial` on a non-array program variant, `ProgramType::StaticMaterial`). Filtering honours `gl_texture_filter`, `gl_texture_filter_anisotropic`; hires/`gl_texture_hqresize*` go through the existing `FGameTexture` scaling (unchanged).
2. Port `OpenGL/Renderers/Legacy/World/Data/**`, `Geometry/**` (incl. `Static/**`, `Portals/FloodFill/**`, `PortalRenderer`, `MidTextureHack`, `CoverWallUtil`, `GeometryRenderer.Sector3D`), `Common/Shared/World/**` (`ViewClipper`, `WorldTriangulator`, `WallVertices`, `WallUV`, `MidTexOpening`, `MiddleDrawSpan`, `TriangulatedWorldVertex`), `Common/World/Triangulation/**`, the `Static*Shader`/`Interpolation*Shader` program classes, `Sky/**`. Flats: `WorldTriangulator` uses UZDoom `FSection` subsector fans produced by `hw_vertexbuilder.cpp` (`CreateVertices` logic moved into `WorldTriangulator.cpp`; `hw_vertexbuilder.*` deleted in M8). Slopes: vertex Z from `secplane_t::ZatPoint`. 3D floors (`F3DFloor`, `sector_t::e->XFloor.ffloors`): emitted like Helion's Sector3D middle walls + planes, flagged dynamic when the control sector has `Movement`. Transfer heights (`sector_t::heightsec`, `hw_fakeflat.cpp` modes incl. deep water/`FAKED_*`): `TransferHeightView` port with UZDoom's fake-flat rules copied from `hw_fakeflat.cpp` into `GeometryRenderer.FakeFlat.cpp`. Render hacks (`hw_renderhacks.cpp`: missing-texture floods, fake bridges) become `FloodFillRenderer` inputs (Helion's flood fill is the same idea). Lightmaps: `StaticVertex` and `DynamicVertex` gain `lightmapUV (vec2)` + `lightmapIndex (float)` attributes (locations 5/6, 7/8) filled from `side_t::lightmap`/`subsector_t::lightmap` like `hw_walls.cpp:1109-1116`; fragment adds `texture(LightMap, vLightmap)` like `main.fp:772-776`.
3. Buffers: `RenderWorldDataManager`/`LightBufferType`: sector light texel buffer (one `uint` per sector floor/ceiling/wall slot, `CreateTexelBuffer(..., VFmt_UInt)`), `sectorColormapTexture`/`sectorFogTexture` texel buffers carrying UZDoom sector `Colormap` (`lightcolor`, `fadecolor`, `desaturation`, `fogdensity`, `LightMode`), updated each frame for sectors whose signature changed. Light modes: truecolor fragment uses the copied `R_DoomLightingEquation` with `uLightLevel/uLightDist/uLightFactor` set per sector from `hw_lighting.cpp`'s `hw_CalcLightLevel`/`hw_GetFog` logic (moved to `Shader/LightLevel.cpp` helpers); palette mode uses Helion's colormap index math. Fog: `gl_fogmode`, `gl_distfog`, MAPINFO `fogdensity/outsidefogdensity/skyfog/brightfog`, `gl_lightadditivesurfaces`, glow (`gl_glow`, GLDEFS glow, UDMF glow colours) via the glow planes already in the contract prelude.
4. Interpolation (D12): `DynamicVertex.prevPos/prevUV` from `DSectorPlaneInterpolation::oldheight/oldtexz` (`r_data/r_interpolate.cpp:44`) and the side's previous offsets; `timeFrac` = `r_viewpoint.TicFrac`. `Helion_RenderViewpoint` does not call `FInterpolator::DoInterpolations` for plane interpolations; `R_SetupFrame` keeps camera interpolation. Actors: `EntityVertex.PrevPos` from `AActor::Prev` (respecting `RF_DONTINTERPOLATE`, `RF_NOINTERPOLATEVIEW` handled by the camera code as today).
5. Sky (D21): `SkySphereRenderer` + `SkySphereTexture` from the level's sky textures (`sky1texture/sky2texture`, double sky, `sky1scrolldelta`, `skystretch`, `r_skymode`, `skyfog`); skybox-style skies (`FSkyBox` textures, GLDEFS `skybox`) become `SkyBoxComponent : ISkyComponent` (cube draw); `gl_noskyboxes` honoured. `SkyGeometryManager` stencil masking as in Helion.
6. Frame driver: `LegacyWorldRenderer::PerformRender` ported verbatim in order (see `local://helion-deep-dive.md §1`), with `m_vanillaRender` wired to `gl_vanillarender` (plane/wall clip framebuffers ported from `OpenGL/Framebuffer/{PlaneClipFrameBuffer,OitFrameBuffer,GLFramebuffer}` as `PPTexture`-style render targets created through the backend's existing render-buffer classes: GL `FGLRenderBuffers`, Vulkan `VkRenderBuffers`).
7. Flip `r_helionrenderer` default to `true`.
8. Acceptance: DOOM2 MAP01/MAP07/MAP30, HEXEN MAP01, SOS_Boom MAP32 render all walls/flats/sky/3D floors; moving doors/lifts/scrollers update; `gl_lightmode` 0,2,8,16 and `vid_colormode 1` visibly change lighting; captures per §V2.
