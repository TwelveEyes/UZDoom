## What to build

All new interfaces live in `src/common/rendering/hwrenderer/data/`; GL implementations in `src/common/rendering/gl/`, Vulkan in `src/common/rendering/vulkan/`. The existing table-driven shader path (`FShaderManager`/`VkShaderManager`) is untouched until M8.

1. **`IRenderProgram`** (`hw_renderprogram.h`, new; no equivalent exists):
   ```cpp
   struct RenderProgramBinding { const char* name; enum Kind { UniformBlock, StorageBuffer, Sampler2D, Sampler2DArray, SamplerBuffer, USamplerBuffer, ISamplerBuffer, Image2D } kind; int binding; /* stage mask */ bool vertex, fragment, compute; };
   struct RenderProgramDesc {
       FString name;                      // debug label
       FString vertexSource, fragmentSource, computeSource; // complete GLSL bodies WITHOUT #version/prelude
       FString defines;                   // "#define X\n" lines prepended after the prelude
       TArray<RenderProgramBinding> bindings;  // uniform blocks (std140 struct text supplied via uniformBlockDecls), buffers, samplers
       TArray<FString> uniformBlockDecls; // one "struct body" per UniformBlock binding, generated with ShaderInputsOutputs::GenerateStruct<T>()
       TArray<ShaderIOEntry> inputsOutputs; // vertex inputs (with VFmt + location), varyings, fragment outputs; reuse hw_shaderpatcher.h ShaderIOEntry
       int numBindingPoints; TArray<FVertexBufferAttribute> vertexAttributes; size_t vertexStride; int instanceDivisorBinding; // -1 = none
       bool isCompute;
   };
   class IRenderProgram { public: virtual ~IRenderProgram() = default; virtual bool IsValid() const = 0; };
   ```
   Backends own compile errors: on failure `I_FatalError("Render program %s: %s", name, log)` exactly as `FShader::Load` does today (`gl_shader.cpp`), so a broken mod shader fails at startup with the same message style.
2. **`DFrameBuffer` factory and draw entry points** (`src/common/rendering/v_video.h`): add
   ```cpp
   virtual IRenderProgram* CreateRenderProgram(const RenderProgramDesc& desc) { return nullptr; }
   virtual IDataBuffer* CreateTexelBuffer(int bindingpoint, int format /* VFmt_Float4 | VFmt_Byte4_UInt | new VFmt_UInt, VFmt_Float */) { return nullptr; } // samplerBuffer/usamplerBuffer backing
   virtual IHardwareTexture* CreateTextureArray(int width, int height, int layers, int numchannels, bool mipmap, const char* name) { return nullptr; }
   virtual void DispatchCompute(IRenderProgram* prog, int gx, int gy, int gz) {}   // no-op when !SupportsCompute()
   virtual bool SupportsCompute() { return false; }  // GL: gl_version >= 4.3 (RFL flag added in gl_interface.cpp); Vulkan: true
   virtual void MemoryBarrierCompute() {}             // GL glMemoryBarrier(GL_SHADER_STORAGE_BARRIER_BIT|GL_TEXTURE_FETCH_BARRIER_BIT); Vulkan pipeline barrier
   ```
3. **`FRenderState` program mode** (`hw_renderstate.h`): add `void SetProgram(IRenderProgram* prog)` (nullptr = back to table shaders), `void SetProgramBuffer(int binding, IBuffer* buf, size_t offset, size_t size)`, `void SetProgramTexture(int binding, IHardwareTexture* tex, int clampmode /* CLAMP_* */, int filter)`, `void SetProgramTexelBuffer(int binding, IDataBuffer* buf)`, `void SetProgramUniforms(int binding, const void* data, size_t size)` (per-draw UBO data; backends stream it like `StreamData`), `void SetBlendEquation(int)`/`SetBlendFunc(src,dst)` wrappers already expressible through `SetRenderStyle` — instead add `void SetCustomBlend(int srcRGB, int dstRGB, int srcA, int dstA, int equationRGB, int equationA)` for OIT (`One/One`, `Zero/OneMinusSrcColor`, `Min`), `void SetColorMask(bool r,bool g,bool b,bool a)` exists, `void SetPolygonOffset(float factor, float units)` (maps to `SetDepthBias`), `void DrawInstanced(int dt, int index, int count, int instanceCount)`, `void DrawIndexedInstanced(...)`.
   - GL (`gl_renderstate.cpp`): in `ApplyShader()` if `mProgram != nullptr` bind `GLRenderProgram::Handle`, upload per-draw uniform blocks via `glBindBufferRange` on a ring UBO (same pattern as `GLDataBuffer::BindRange`), bind textures with `glActiveTexture(GL_TEXTURE0+binding)` and texel buffers as `GL_TEXTURE_BUFFER` (`glTexBuffer`). Skip the legacy `glUniform*` pushes.
   - Vulkan (`vk_renderstate.cpp`): `VkRenderProgram` holds `VulkanPipelineLayout` (set 0 fixed, set 1 HW buffers — layout-compatible as required by the comment at `vk_renderstate.cpp:514-521` — set 3 program bindings) and a `std::map<VkPipelineKey, VulkanPipeline>` cache keyed by the existing `VkPipelineKey` fields plus blend/colormask/instancing; `Apply()` with `mProgram` set follows the `BeginExternalDraw` path (`vk_renderstate.cpp:567`) generalised: bind pipeline, sets 0/1 with dynamic offsets, set 3 descriptor set built from the current `SetProgram*` bindings (descriptor pool per program, updated when bindings change). Texel buffers = `VK_DESCRIPTOR_TYPE_UNIFORM_TEXEL_BUFFER` with `VkBufferView`. Compute programs: `ComputePipelineBuilder` as in `vk_levelmeshrenderer.cpp:181`.
4. **GLSL prelude generation** (`hw_shaderpatcher.cpp`): add `FString GenerateProgramPrelude(const RenderProgramDesc&, bool isVulkan, bool isFrag, bool isCompute)` that emits `#version 330 core` (GL) / `#version 460` (Vulkan, as `vk_shader.cpp` does today), `layout(std140, binding=N) uniform <Name> { ... }` (GL) or `layout(set=3, binding=N)` (Vulkan), sampler/texel buffer declarations, and the inputs/outputs through the existing `GenerateInputsOutputs` logic with the program's `ShaderIOEntry` list. Vertex inputs always get explicit `layout(location=N)` on both backends (Helion's programs use explicit locations; GL 3.3 supports `layout(location)` for inputs).
5. **Texture arrays**: `FHardwareTexture` (`gl_hwtexture.h`) gains `CreateTextureArray(...)` + `UploadLayer(int layer, const unsigned char* buffer, int w, int h)`; `VkHardwareTexture` (`vk_hwtexture.h`) gains the same with `VK_IMAGE_VIEW_TYPE_2D_ARRAY`. Add to `IHardwareTexture`: `virtual void UploadLayer(int layer, const unsigned char* buffer, int w, int h) {}`.
6. **Startup precompile**: `DFrameBuffer::GetShaderCount()` returns table count + `HelionProgramRegistry::Count()`; `CompileNextShader()` compiles table shaders first, then calls `HelionProgramRegistry::CompileNext(screen)`. `HelionProgramRegistry` lives in `src/rendering/helion/OpenGL/Shader/ProgramRegistry.{h,cpp}` (UZDoom-only; keyed by `(ProgramType, materialShaderIndex, EPassType, flags)`; `Count()` = programs × (`defaultshaders` count − 1 + `usershaders.Size()`) × `MAX_PASS_TYPES`, computed from the same tables `hw_shaderpatcher.cpp:409` uses). GL binary cache: extend `LoadShaders/SaveShaders` (`gl_shader.cpp:107/156`) keys with the program name hash so Helion programs are cached too.
7. Acceptance: tree builds on both backends; a throwaway program (`StaticShader` body with constant colour) created through `CreateRenderProgram` draws one instanced triangle through `FRenderState::SetProgram` + `DrawInstanced` into the scene buffer when `r_helionrenderer_test 1` (temporary `CVAR_NOSAVE`, removed in M2). Smoke per Verification §V1.

## Comments
- 2026-10-20 (BackendProgramApi): M1 implemented on both backends; clean Debug build (HAVE_VULKAN=ON, no warnings in touched files); V1 smoke captured on GL and Vulkan (`/tmp/helion-smoke/m1-{gl,vk}-t1/MAP01_30.png` triangles over the scene, `-t0` baselines unchanged).
  - **Built**: `hw_renderprogram.cpp` (`GenerateProgramPrelude`), `gl_renderprogram.{h,cpp}` (`GLRenderProgram`, `GLTexelBuffer`, `GLTextureArray`, `GLRenderTarget`), `gl_renderstate_program.cpp` (FGLRenderState program mode, uniform ring, instancing, custom blend, render targets, scene colour copy), `vk_renderprogram.{h,cpp}` (`VkRenderProgram` + pipeline cache, `VkTexelBuffer`, `VkTextureArray`, `VkProgramRenderTarget`), `vk_renderstate_program.cpp` (set 3 descriptors, uniform ring, render target passes, scene copy/depth sampling, compute), `hw_programtest.{h,cpp}` (`r_helionrenderer_test`, called from `hw_entrypoint.cpp` before `PostProcessScene`; removed in M2).
  - **Deviations**: (1) step 6 is a hook, not the registry: `DFrameBuffer::ExtraShaderCount` / `CompileNextExtraShader` (null function pointers); `GetShaderCount` adds `ExtraShaderCount()`; both backends run the table shaders first, then the extra hook. GL binary cache key now includes the program name (`LoadCachedProgramBinary/SaveCachedProgramBinary(..., name)`). (2) Vulkan prelude uses `#version 450` (the Helion programs need nothing from 460) and defines `VULKAN_COORDINATE_SYSTEM`, `gl_VertexID`/`gl_InstanceID` aliases; vertex shaders must apply `gl_Position.z = (z + w) / 2` under it exactly like `main.vp`. The set 2 slot of the program pipeline layout is an empty layout (set 3 = program bindings); sets 0/1 and push constants are layout compatible with the table pipelines. (3) GL has no `layout(binding)` for blocks/samplers in 3.3: samplers use unit `ProgramGLTextureUnit(binding)` (= binding, skipping units 16/17 which the table path keeps for shadow map / light map), uniform/storage blocks bind at `ProgramGLBufferBindingBase (8) + binding`; fixed up with `glUniform1i`/`glUniformBlockBinding` after link (SSBOs/images use `layout(binding)` in 4.3+). (4) Contract additions: `FRenderState::OnSetProgram` virtual hook, `SetCustomBlendAttachment` + `FCustomBlendState::attachment[3]` (per-attachment blend for OIT; needs GL 4.0 / Vulkan `independentBlend`, otherwise attachment 0's state is used), `IHardwareTexture::GenerateMipmaps()` (`UploadLayer` no longer generates mipmaps; requested by HelionTextures), `DFrameBuffer::GetMaxTextureArrayLayers()`, `RFL_COMPUTE_SHADER`, `IDataBuffer` texel buffers and `IRenderTarget` implementations, `FHardwareTexture`/`VkHardwareTexture` untouched (arrays are separate `GLTextureArray`/`VkTextureArray` classes). (5) ZVulkan: `GraphicsPipelineBuilder::AddVertexBufferBinding(..., bool instanced)`; `VkCommandBufferManager::DeleteList::AddGeneric` + `DeleteGeneration`.
  - **Limitations**: render targets that share the scene depth buffer (`shareSceneDepth`) are not supported while the scene is multisampled (GL `gl_multisample`, Vulkan multisampling): they render without depth and print a warning; M3 must run the Helion scene with multisampling off (or resolve before OIT). Scene depth sampling (`SetProgramSceneTexture(.., true)`) is non-multisample only. Program objects must be destroyed before the device (the test hook leaks its resources on purpose); Helion's renderer needs a shutdown hook (M2).
  - **Not exercised**: compute programs, texel buffers, texture arrays, render targets, `CopySceneColor`, GL binary shader cache round trip and the GL 3.3 fallback were compiled but not run in M1 (the smoke exercises programs, instancing, per-draw uniform blocks, vertex/instance buffers and custom blend/disable-blend on both backends).
