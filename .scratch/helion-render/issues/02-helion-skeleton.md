## What to build

1. Port, under `src/rendering/helion/`, in dependency order: `Common/Shared/{RenderInfo,Frustum,FrustumPlane,OldCamera}`, `Common/World/{Camera,ViewMath}`, `Common/Commands/Types/DrawWorldCommand`, `Common/Context/WorldRenderContext`, `Common/Renderers/{IWorldRenderContext,IRenderableSurfaceContext,IRenderableSurface}`, `OpenGL/Shader/{RenderProgram,ProgramUniforms,ProgramAttributes}`, `OpenGL/Vertex/{VaoAttribute,VertexAttributes,Attributes,VertexArrayObject}`, `OpenGL/Buffer/{BufferObject,ArrayBufferObject,VertexBufferObject}`, `OpenGL/VertexPipeline`, `OpenGL/Renderers/Legacy/World/{RenderProgramBase,ShaderUniforms,VertexOptions,UvFlags,StaticVertex,DynamicVertex}`, `OpenGL/Renderers/Legacy/World/Shader/{ShaderVars,VertexFunction,FragFunction,LightLevel,SectorColorMap,PlaneClip}`, `OpenGL/Renderers/WorldRenderer`, `OpenGL/Renderers/Legacy/World/LegacyWorldRenderer{,.Bsp,.BspHeuristics}`, `OpenGL/GLWorldRenderContext`, `Renderer`, `Renderer.World`, `RenderBlock`, `SectorUpdates`, `BindTextures`, `ColorMapBuffer`.
   - `RenderProgram`: `VertexShader()/FragmentShader()` return GLSL text; the ctor builds a `RenderProgramDesc` and calls `screen->CreateRenderProgram`. `ProgramUniforms` keeps Helion's name→location API but writes into the program's per-draw uniform struct (a `TArray<uint8_t>` + offset table generated from `GenerateStruct<T>`), flushed by `FRenderState::SetProgramUniforms` before each draw.
   - `VertexPipeline<T>`: wraps one `IVertexBuffer` (+ optional index buffer) with the attribute table; `DrawArrays(prim)` → `FRenderState::Draw`, instanced variant → `DrawInstanced`. Fix Helion's defect (`DrawArrays(PrimitiveType,int,int)` hard-codes `Lines`): the port honours the argument.
   - `ShaderVars`: `PaletteColorMode` driven by `vid_colormode`; `ReversedZ`, `Depth` omitted (D11); `SoftwareSpriteEmulation`/`EmulateInvulnerabilityColorMap` driven by `gl_vanillarender`/`gl_emulateinvulncolormap`.
   - `FragFunction`: emit, in this order, the UZDoom contract prelude (verbatim text of `struct Material` + prototypes from `wadsrc/static/shaders/glsl/main.fp:18-37`, the `uniform` set listed in `gl_shader.cpp:305-399` expressed as one `UniformBlock` named `StreamData` using `GenerateStruct<StreamData>()` from `hw_renderstate.h:191`, the varyings `vTexCoord/vColor/pixelpos/glowdist/gradientdist/vWorldNormal/vEyeNormal/vLightmap` from `hw_shaderpatcher.cpp:350-359`, `timer`, `tex`, `texture2..texture12`, `ShadowMap`, `LightMap`, `lights[]`), then Helion's own declarations (`lightLevelFrag`, `sectorColorMapIndexFrag`, OIT outputs), then the material lump text chosen exactly as `gl_shader.cpp:523-568` does (`func_defaultmat.fp`/user shader, `OLD_PROCESSLIGHT`, `LEGACY_USER_SHADER`, `func_defaultlight.fp` injection), then Helion's `main()` which: computes `vTexCoord`/`pixelpos` equivalents from Helion varyings, calls `SetupMaterial`/`ProcessMaterial`, applies Helion light level (truecolor: `LightLevel.cs` math fed with UZDoom `R_DoomLightingEquation` semantics by `gl_lightmode`; palette: colormap buffer lookup), fog, OIT write. `getTexel`/`desaturate`/`applyFog`/`R_DoomLightingEquation` are copied from `main.fp` into `FragFunction` text so mods' `getTexel()` calls still resolve. For `boundTexture` (array) programs, `tex` is declared as `sampler2DArray` and `getTexel` samples with `boundTextureIndex`; for per-material programs `tex` is `sampler2D` as today.
2. **World hooks** (`src/gamedata/r_defs.h`, playsim): add `sector_t::renderDynamic`, `side_t::renderDynamic`, `sector_t::renderSignature` (`struct { double floorD, ceilD; int floorTex, ceilTex; int16_t light; uint32_t color, fade; float xoff[2], yoff[2], xscale[2], yscale[2], angle[2]; }`) and `side_t::renderSignature` (`{ int tex[3]; float xoff[3], yoff[3], xscale[3], yscale[3]; uint32_t flags; int16_t light; }`). Raise Helion's events from: `DMover`/`DMovingFloor`/`DMovingCeiling` (`p_floor.cpp`, `p_ceiling.cpp`, `p_plats.cpp`, `p_doors.cpp`, `p_pillar.cpp`, `p_lights.cpp` for light-only changes do NOT set Movement) — `SectorMoveStart` in the thinker constructor (`sector->renderDynamic |= Movement`), `SectorMoveComplete` in the thinker destructor/`Destroy` (clear bit, call `StaticCacheGeometryRenderer::HandleSectorMoveComplete`); `DScroller` (`p_scroll.cpp`) sets `Scroll`/`ScrollY` on the side; `sector_t::SetAllVerticesDirty()` (`r_defs.h:1147`) additionally calls `Helion::World::SectorUpdates::PlaneTransformed(this)`; `side_t::SetTexture`, `sector_t::SetTexture` call `SideTextureChanged`/`PlaneTextureChanged`. Per frame, `LegacyWorldRenderer::ValidateSignatures()` (UZDoom-only method in `LegacyWorldRenderer.Validate.cpp`) compares every sector/side signature with the cached copy and marks mismatches dirty (same code path as the event). 3D-floor control sectors set `TransferHeights` on every target sector at `P_Spawn3DFloors` time; polyobject sides get `Polyobject`.
3. **Render blockmap**: port `BlockMap.cs` render parts into `RenderBlockMap` (block size 128 units like Helion's `Dimension`; per block: `TArray<sector_t*>`, `TArray<side_t*>`, intrusive `AActor* headRenderEntities` using new `AActor::renderBlockNext/renderBlockPrev/renderBlock` fields). Hooks: `AActor::LinkToWorld`/`UnlinkFromWorld` (`p_maputl.cpp`), polyobject move/rotate (`po_man.cpp`) relink the polyobject's sides.
4. **Entry point**: `src/rendering/helion/Entrypoint.{h,cpp}` (UZDoom-only) provides `sector_t* Helion_RenderViewpoint(FRenderViewpoint&, AActor* camera, IntRect*, float fov, float ratio, float fovratio, bool mainview, bool toscreen)` mirroring `hw_entrypoint.cpp:88-183` (shadow map setup, eyes loop, `SetSceneRenderTarget`, `PostProcessScene` with the 2D callback) but calling `Renderer::Render(DrawWorldCommand)`. In `hw_entrypoint.cpp` `RenderViewpoint`, `WriteSavePic` and the canvas-texture path (`RenderView`, `screen->RenderTextureView`) dispatch on `r_helionrenderer` (new `CVAR_NOSAVE|CVAR_NOINITCALL` bool in `Entrypoint.cpp`, default `false` until M3 renders a full level, then `true`). `DrawEndScene2D` and `EndDrawScene` equivalents (`HWDrawInfo::EndDrawScene` draws blends; keep by calling the same `V_CalcBlend`/`Draw2D` logic moved into `Entrypoint.cpp` in M8).
5. Acceptance: with `r_helionrenderer 1`, DOOM2 MAP01 loads and renders the sky sphere placeholder colour and nothing else without crashing on GL and Vulkan; `r_helionrenderer 0` renders as before.
