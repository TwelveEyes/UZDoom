## What to build

1. New `src/rendering/helion/OpenGL/Renderers/Legacy/World/Lights/` (UZDoom-only, Helion style): `ClusterGrid.{h,cpp}` (tile size 64×64 px at scene resolution, 24 log-depth slices between `near` and the frustum far/`MaxDistance`; cluster count recomputed on resize), `ClusterLightBuffer.{h,cpp}` (per-frame light records in the existing `FLightBuffer` layout `hw_lightbuffer.h` — header `vec4(modifiedCount, additiveCount, subtractiveCount, 0)` followed by the three ranges, exactly what `func_defaultlight.fp` iterates; one record list per cluster, max 128 lights/cluster, overflow drops farthest with a one-time `Printf(PRINT_HIGH, ...)` warning), `ClusterAssignProgram.{h,cpp}` (compute: `lightcluster.comp` GLSL text in the class, sphere/cone vs cluster AABB, writes cluster offset buffer + record lists; input = flat light array `vec4 posRadius, color, spotDir, params(shadowIndex, flags)` built from `FDynamicLight` list on the CPU each frame), `ClusterAssignCpu.{h,cpp}` (same algorithm in C++ for `!SupportsCompute()`, output buffers identical). Fragment prelude (FragFunction): `int uLightIndex;` global + `uLightIndex = clusterOffsets[clusterIndex(gl_FragCoord, pixelpos.w)];` as the first statement of `main()`; `lights[]` SSBO (GL ≥ 4.3 / Vulkan) or UBO fallback (`NUM_UBO_LIGHTS`) bound as today; `uLightIndex = -1` when the cluster is empty (mod shaders already test `uLightIndex >= 0`).
2. Lights: `FDynamicLight` list from `Level->lights` (`a_dynlight.h`), `LF_*` flags, `LEVEL3_ATTENUATE`/`LF_ATTENUATE`, `LF_SPOT`, `LF_DONTLIGHTMAP` (excluded for world geometry), `LF_DONTLIGHTACTORS`/`LF_DONTLIGHTOTHERS`/`LF_DONTLIGHTSELF` (handled in the sprite probe as today), `r_dynlights`/`gl_lights`, `gl_lights_size`? (verify in `hw_dynlightdata.cpp`; honour every CVar the feature inventory lists), `gl_attenuate`.
3. Shadowmaps: keep `IShadowMap`/`hw_shadowmap.cpp`, `doom_aabbtree.{h,cpp}` (line AABB tree, `Level->aabbTree`), `gl_light_shadowmap`, `gl_shadowmap_quality`, `gl_shadowmap_filter`; `UpdateShadowMap` called from `Helion_RenderViewpoint` as in `hw_entrypoint.cpp:94-107`. Vulkan `VkRaytrace::SetLevelMesh` is fed a wall-only `hwrenderer::LevelMesh` built by new `Lights/ShadowMesh.{h,cpp}` from `Level->lines` (one quad per one-sided line / per blocking two-sided line, full height `-32768..32768`), replacing `DoomLevelMesh` as the source; `hw_levelmesh.h` keeps only the `LevelMesh` vertex/index struct it needs (everything else in that header deleted in M8).
4. Acceptance: `lighttest.wad` renders dynamic lights on walls/flats/sprites/models on GL and Vulkan; `SupportsCompute()==false` forced via temporary env `UZDOOM_FORCE_CPU_CLUSTERS=1` (read in `ClusterLightBuffer` ctor, removed after the capture) produces the same capture within tolerance; `gl_light_shadowmap 1` shows shadows on Vulkan; captures per §V2.
